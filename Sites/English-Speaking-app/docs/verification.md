## Limits / still to test

- No physical Android/iOS device, emulator installation, signed APK, EAS submission or store build was tested.
- The browser microphone request stayed pending in this environment. Timeout/error and microphone-free fallback are implemented, but successful native recording, replay, actual audio-file deletion, denied-permission recovery and the 60-second cap need hardware testing. The app does not claim pronunciation assessment.
- Speech availability depends on installed OS/browser English voices; offline playback and silent-switch behavior need testing on each target device. No bundled human recordings are included.
- Bundled content and local storage do not fetch a backend. Native airplane-mode execution was not tested. Web has no service worker and needs its server on reload.
- Screen readers, OS-level maximum font scale, hardware back navigation, native share sheet and app force-stop/relaunch still need device testing. Web reload persistence was tested.
- New content has not been independently reviewed by a Marathi teacher. See content-review.md.
- 35 dependency entries remain affected (12 moderate, 23 high). See dependency-review.md for root advisories and remediation constraints.
